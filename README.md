## The entry

> 🌋

One emoji for my dream vacation: standing at the edge of an erupting volcano, lava glowing below — the most alive place on earth.

## How it works

`main.py` (Python 3, standard library only) writes the emoji to `/output/entry.txt` deterministically: it writes a temp file, then atomically replaces the output and sets mode 644.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
